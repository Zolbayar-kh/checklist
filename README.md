# Миний checklist: өөрийн бүртгэлтэй хувилбар

Утсанд апп шиг суудаг, интернетгүй үед ч ажилладаг, имэйлээрээ нэвтэрч бүх төхөөрөмж дээрээ ижил өгөгдөлтэй ашигладаг хувилбар.

- **Hosting:** GitHub Pages (үнэгүй)
- **Нэвтрэлт ба өгөгдөл:** Supabase (үнэгүй багц хувийн хэрэглээнд хангалттай)

Нийт 15–20 минут орно.

---

## 1. Supabase төсөл үүсгэх

1. https://supabase.com руу ороод **GitHub бүртгэлээрээ нэвтэрнэ**.
2. **New project** дарна.
   - Name: `checklist`
   - Database Password: хүчтэй нууц үг үүсгээд хаа нэг тийш хадгална (апп-д хэрэггүй)
   - Region: танд хамгийн ойрыг сонгоно (жишээ нь Singapore эсвэл Tokyo)
3. Төсөл бэлэн болтол 1–2 минут хүлээнэ.

## 2. Хүснэгт үүсгэх

1. Зүүн цэсний **SQL Editor** → **New query**.
2. `supabase.sql` файлын агуулгыг бүхэлд нь хуулж тавиад **Run** дарна.
3. "Success" гэж гарвал болсон.

Энэ нь хэрэглэгч бүрт нэг мөр хадгалдаг хүснэгт үүсгэнэ. Хүн бүр зөвхөн **өөрийнхөө** өгөгдлийг харж, засах дүрэм (RLS) хамт тохируулагдана.

## 3. Түлхүүрээ хуулах

1. **Project Settings** (араа дүрс) → **API** хэсэг. Шинэ цэсэнд **Data API** эсвэл **API Keys** гэж байж болно.
2. Хоёр утгыг хуулна:
   - **Project URL**: `https://xxxx.supabase.co` хэлбэртэй
   - **anon public** түлхүүр: урт текст
3. `config.js` файлыг нээгээд `ЭНД_PROJECT_URL`, `ЭНД_ANON_KEY` гэсэн хэсгийг солино.

> ⚠️ **service_role** түлхүүрийг хэзээ ч бүү оруул. **anon** түлхүүр нийтэд ил байхад аюулгүй, учир нь RLS дүрэм хамгаална.

## 4. GitHub Pages дээр байршуулах

1. https://github.com/new хуудсанд:
   - Repository name: `checklist`
   - **Public** сонгоно. Үнэгүй багцад GitHub Pages зөвхөн public repo дээр ажилладаг. Өгөгдөл тань repo-д биш, Supabase-д хадгалагдана.
   - **Create repository**
2. Шинэ repo дотор **uploading an existing file** холбоос (эсвэл **Add file → Upload files**) дээр дарна.
3. Энэ хавтасны **бүх файл, хавтсыг** чирч оруулна: `index.html`, `config.js`, `sw.js`, `manifest.webmanifest`, `icons/`, `vendor/` гэх мэт. Хавтасны бүтэц хэвээрээ байх ёстой.
4. **Commit changes** дарна.
5. **Settings → Pages** хэсэгт:
   - Source: **Deploy from a branch**
   - Branch: **main**, хавтас: **/ (root)** → **Save**
6. 1–2 минутын дараа дээд хэсэгт апп-ийн хаяг гарна: `https://ТАНЫ-НЭР.github.io/checklist/`

## 5. Supabase-д апп-ийн хаягийг бүртгэх

Имэйл баталгаажуулах болон нууц үг сэргээх холбоосыг зөв хаяг руу чиглүүлэхэд хэрэгтэй.

1. Supabase → **Authentication → URL Configuration**
2. **Site URL**: `https://ТАНЫ-НЭР.github.io/checklist/`
3. **Redirect URLs** хэсэгт мөн ижил хаягийг нэмнэ.

**(Заавал биш)** Ганцаараа ашиглах бол **Authentication → Sign In / Providers → Email** хэсэгт **Confirm email**-ийг унтрааж болно. Тэгвэл бүртгүүлмэгц шууд нэвтэрнэ. Асаалттай үлдээвэл бүртгүүлсний дараа ирсэн имэйлийн холбоос дээр дарж баталгаажуулна.

> Supabase-ийн үнэгүй имэйл илгээгч цагт цөөн тооны захидал илгээдэг. Мөн зөвхөн төслийн гишүүдийн имэйл рүү илгээдэг тул таны өөрийн имэйл рүү асуудалгүй очно. Найзуудаа урих үед өөр имэйл үйлчилгээ (SMTP) холбох шаардлагатай.

## 6. Утсан дээрээ суулгах

1. Утасныхаа браузерээр `https://ТАНЫ-НЭР.github.io/checklist/` хаягийг нээнэ.
2. **Бүртгүүлэх** → имэйл, нууц үгээ оруулна.
3. Суулгах:
   - **iPhone (Safari):** Хуваалцах товч → **Add to Home Screen** → **Add**
   - **Android (Chrome):** апп дотор гарч ирэх "Утсанд апп болгон суулгах" товч, эсвэл ⋮ цэс → **Install app** / **Add to Home screen**
4. Компьютер дээрээ ч мөн адил хаягаар орж, ижил имэйлээр нэвтэрнэ. Өгөгдөл тань хоёр төхөөрөмж дээр ижил харагдана.

---

## Ашиглах үед

- **Интернетгүй үед** өөрчлөлтүүд утсан дээр хадгалагдаж, холбогдох үед автоматаар синк хийгдэнэ.
- Хоёр төхөөрөмж дээр зэрэг засвал **хамгийн сүүлд хадгалсан** нь үлдэнэ. Нэг төхөөрөмжөөсөө нөгөө рүү шилжихдээ апп-аа нээгээд 1–2 секунд хүлээвэл синк хийгдэнэ.
- **Профайл** (Нүүр хуудасны зүүн дээд буланд байгаа дугуй товч) хэсгээс: синк хийгдсэн эсэх, гарах, **нөөц файл татах / сэргээх**.
- Claude дээрх хувилбараас өгөгдлөө шилжүүлэх боломж одоогоор байхгүй тул энэ хувилбарыг шинээр бөглөнө. Жишээ бичлэгүүдийг Нүүр хуудасны доорх "Бүх жишээг арилгах" товчоор арилгана.

## Апп-аа шинэчлэх

Файлуудыг GitHub-д дахин оруулж (Upload files → ижил нэрээр нь солих) commit хийнэ. `sw.js` доторх `CACHE = 'checklist-v1'`-ийн дугаарыг `v2`, `v3` гэж нэмэгдүүлбэл утсан дээрх хувилбар хурдан шинэчлэгдэнэ.

## Файлууд

| Файл | Юу хийдэг |
|---|---|
| `index.html` | Апп өөрөө |
| `config.js` | Supabase-ийн хаяг ба түлхүүр (**та бөглөнө**) |
| `supabase.sql` | Хүснэгт ба хамгаалалтын дүрэм |
| `sw.js` | Интернетгүй ажиллах (service worker) |
| `manifest.webmanifest`, `icons/` | Утсанд апп болгон суулгах |
| `vendor/` | Supabase-ийн JavaScript сан (MIT лиценз) |
