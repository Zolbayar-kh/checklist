Утсанд апп болгон суулгах

iPhone, iPad дээр Safari-аар нээгээд:

  1. Доод хэсгийн Хуваалцах товч (дээшээ сумтай дөрвөлжин)
  2. Add to Home Screen (Нүүр дэлгэцэнд нэмэх)
  3. Баруун дээд буланд Add

Android Chrome: баруун дээд ⋮ цэс → Add to Home screen эсвэл Install app. Компьютерийн Chrome, Edge: хаягийн мөрний баруун талд байгаа суулгах дүрс.
